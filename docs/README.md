# ⚔️ TypeFight Arena

A real-time multiplayer typing battle game built using the MERN Stack and Socket.IO.

---

## Features

- Real-time typing battles
- Matchmaking
- Leaderboard
- Tournament mode
- Admin panel

---

## Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Socket.IO
